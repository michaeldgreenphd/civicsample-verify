Migration 0008 (`0008_trial_packet_and_concurrency_guards.sql`, version `4.0.5-trial-packet-concurrency-guards`) closes remaining database, export, and concurrency gaps found during the independent audit:

- **Step-2 trial-context packet freeze & two-step `TRIAL_AREA` enforcement**: `private.trial_context_packets_v4_guard()` prevents post-freeze insertions, updates, or deletions on `public.trial_context_packets` for held-out cases (`HELDOUT_PRIMARY`, `HELDOUT_EXTENSION_UNAPPROVED`, `HELDOUT_EXTENSION_APPROVED`). `private.case_levels_v4(p_case_id)` and `private.case_design_v3_v4_guard()` require `TRIAL_AREA` cases to use two-step determination levels (`DESCRIPTOR_LEVEL_IN_TRIAL_CASE` and `TRIAL_LEVEL`), and `rpc_freeze_v4` verifies that every held-out `TRIAL_AREA` case has a Step-2 `trial_context_packets` row and no extraneous prediction levels before freezing.
- **Snapshot and adjudication concurrency serialization**: `rpc_snapshot_judgments_v4()` now requires `READ COMMITTED` transaction isolation and locks `cases, assignments, reviews, trial_step1_records, adjudications, judgment_snapshots_v4` in `SHARE ROW EXCLUSIVE MODE`. `rpc_record_adjudication_v3` and `private.adjudications_before_insert()` require `READ COMMITTED`, lock `public.adjudications` in `SHARE ROW EXCLUSIVE MODE`, and coordinate via `private.v4_lock_state` (`SELECT ... FOR SHARE` / `FOR UPDATE` using PostgreSQL `EvalPlanQual`) so concurrent `READ COMMITTED` sessions inside `SELECT rpc_...()` portals observe newly committed freeze, reference-lock, and primary-adjudication transitions.
- **Module B adjudication basis validation**: `private.assert_mb_adjudication_semantics_v4()` validates `mb_adjudications_v4` basis, status, decision, and unresolved reason before insertion and before `rpc_lock_mb_reference_v4()`.
- **Database-to-exporter-to-Python round trip**: `exportV4SyntheticBundleFromDb` queries the live SQL views (`v_independent_judgments_v4`, `v_adjudicated_reference_v4`, `v_frozen_predictions_v4`) and obtains integrity flags exclusively from `rpc_verify_frozen_predictions_v4()` and `rpc_verify_judgment_snapshot_v4()`. Both the TypeScript exporter and Python validator enforce `extension_approved_by_amendment` vs `amendment_id` consistency and `unit_type`/`nct_id`/`determination_level` invariants.
- **Native PostgreSQL disposable-DB harness, canonical case authoring, and synthetic invite/JWT scaffolding**: `tests/postgres-native.test.ts` uses the `pg` client and `withDisposablePostgresDatabase()` to create and tear down an isolated `verify_disp_...` test database (never dropping schemas in the supplied database, with regression coverage proving unrelated existing data in the supplied database is preserved) and exercises multi-session concurrency across freeze vs case withdrawal, freeze vs packet versioning, concurrent review amendments, concurrent formal adjudications, reference lock vs assignment withdrawal, and reference lock vs migration `0008` preflight. `src/lib/auth.ts` provides synthetic invite/JWT test scaffolding (not implemented TOTP/MFA; requires explicit `aal2` when MFA is required rather than defaulting to `aal2`, and permanently rejects revoked JWTs even after re-inviting and re-claiming), while `src/server/admin-workflows.ts` and `migrations/0008_trial_packet_and_concurrency_guards.sql` enforce canonical `EvidencePacket` and `TrialPacket` shapes for synthetic pilot case authoring (verified in a served-browser Playwright scenario).
